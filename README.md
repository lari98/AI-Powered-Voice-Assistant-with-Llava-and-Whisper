# 🗣️ AI Powered Voice Assistant with Llava 1.5 & Whisper  

Unlock the power of AI to build your own intelligent voice assistant! 🚀  

## 📌 Overview  
This tutorial walks you through creating a cutting-edge voice assistant using:  
- **Llava 1.5 7B** – A multimodal LLM for advanced image and text understanding  
- **Whisper by OpenAI** – Accurate speech-to-text conversion  
- **Gradio** – A simple and interactive UI for easy deployment  
- **gTTS** – Realistic text-to-speech functionality  

Whether you want to enhance a hobby project, showcase AI capabilities, or build an MVP, this guide provides the tools and knowledge to bring your vision to life.  

## ✨ Features  
✔️ **Multimodal AI:** Understands both images and text  
✔️ **Speech-to-Text:** Converts spoken input into text with high accuracy  
✔️ **Text-to-Speech:** Generates realistic voice responses  
✔️ **User-Friendly UI:** Built with Gradio for easy interaction  

## 🛠️ Tech Stack  
- Python  
- Transformers (Hugging Face)  
- OpenAI Whisper  
- Llava 1.5 7B  
- Gradio  
- gTTS
